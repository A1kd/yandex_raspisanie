# Расписание Путешествий (yandex_raspisanie)

Учебный проект: приложение поиска расписания транспорта на API Яндекс Расписаний.
SwiftUI, MVVM, минимальная версия iOS 17.

## Что сделано

- **Спринт 1** — сетевой слой: 8 сервисов API через OpenAPI Generator.
- **Спринт 2** — вёрстка экранов по макету Figma: заставка, главный экран, выбор
  города и станции, список рейсов, фильтры, экраны ошибок; светлая и тёмная темы.

## Структура

```
TravelSchedule/
├── App/           точка входа, заставка и таббар
├── DesignSystem/  цвета, шрифты и переиспользуемые компоненты из UI-kit макета
├── Models/        City, Station, Carrier, RouteSegment, RouteFilter, AppError
├── Mock/          данные из макета за протоколами CityProviding и RouteProviding
├── Features/      экраны, каждый со своей ViewModel
├── Services/      сетевой слой из первого спринта
└── Resources/     Assets.xcassets: цвета, иллюстрации, иконки
```

## Навигация

Таббар с двумя вкладками: расписание и настройки. Внутри вкладки расписания —
`NavigationStack`: список рейсов, фильтры и карточка перевозчика открываются push-переходом.
Выбор города и станции показывается в `fullScreenCover` и перекрывает таббар,
стрелка на экране выбора города закрывает его целиком.

## Данные

В этом спринте экраны работают на моках из макета (`Mock/MockData.swift`).
Провайдеры спрятаны за протоколами `CityProviding` и `RouteProviding`, поэтому
в следующем спринте вместо них подставляются сервисы из `Services/` без правок экранов.

## Как посмотреть экраны ошибок

Экраны «Ошибка сервера» и «Нет интернета» показываются на любом экране с загрузкой.
Чтобы их вызвать, откройте вкладку настроек и переключите «Симуляция ошибки»,
затем вернитесь на главный экран и выполните поиск.

## Сборка

Проект генерируется из `project.yml`:

```
xcodegen generate
open TravelSchedule.xcodeproj
```
